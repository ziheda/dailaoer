# 逮老二微信小游戏客户端

此文件夹可以直接导入微信开发者工具，项目类型为“小游戏”。

## 导入

1. 在微信开发者工具顶部选择“项目 → 导入项目”。
2. 目录选择本文件夹，而不是服务器压缩包。
3. AppID 填写你在微信公众平台创建的小游戏 AppID；只看界面时可暂用测试号。
4. 导入后点击顶部“编译”。

## 本机联调

默认连接地址是：

```text
ws://127.0.0.1:3000/ws
```

请先启动 `online-card-server`。开发阶段需要在开发者工具右上角“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

## 真机与正式环境

编辑 `js/config.js`，把地址改成真实服务地址，例如：

```text
wss://game-api.example.com/ws
```

并在微信公众平台“开发管理 → 开发设置 → 服务器域名”中加入：

```text
wss://game-api.example.com
```

正式环境必须使用已备案域名和有效 HTTPS/WSS 证书。
